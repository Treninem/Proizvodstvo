ВЕРСИЯ БЕЗ ПУБЛИЧНОГО САЙТА

В составе остаются Telegram-бот, рабочие чаты и закрытый Telegram Mini App.
Публичная витрина, каталог, заказы и отдельный вход по логину удалены.

Перед запуском:
1. Вставьте BOT_TOKEN в .env.
2. После получения HTTPS-домена заполните PUBLIC_BASE_URL.
3. Запустите start_linux.sh или python -m app.runtime.
4. Mini App откроется по адресу PUBLIC_BASE_URL/mini только с проверкой Telegram initData.

Порт уже установлен: 3000.
Владелец уже установлен: 2097006037.
Остальные доступы выдаются только через меню владельца.
