## Что уже реализовано и должно быть сохранено
Подробности в STEP82_MEMORY.md и README_START.txt. Нельзя вырезать накопленный функционал ради упрощения.

Ключевые инварианты:
- мультитенантность: фирмы полностью изолированы;
- создатель Telegram-группы получает админ-доступ только к своей фирме;
- системный OWNER не получает скрытый доступ к данным фирм через обычный интерфейс;
- отдельное «🔐 Системное меню» видно только OWNER;
- версия видна только OWNER в системном меню;
- Mini App: Производство · Склад · План · Отчёты · Ещё;
- физический склад: населённый пункт → площадка → участок → отдел → место хранения;
- двухсторонние передачи с резервированием, приёмкой, расхождениями и запретом двойной приёмки;
- Excel импорт только preview → confirm, с tenant-проверками и аудитом;
- Excel экспорт производственных ведомостей;
- роли, сотрудники, отделы, оборудование, качество, ТО, задания, смены, заявки, партии, пополнение, отчёты, диагностика и резервное копирование должны остаться рабочими;
- недоступные функции не показывать в UI и обязательно блокировать сервером;
- данные одной фирмы никогда не должны быть доступны другой фирме;
- системное меню владельца платформы не смешивать с обычным меню организации.
